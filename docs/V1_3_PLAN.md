# V1.3 사진관리 · 액자 출력 개선 계획

## 사용자 피드백
- 첫 화면에서 마지막 한 글자만 줄바꿈됨.
- 하트가 길고 계단형이라 실루엣이 어색함.
- 편집 중 여러 사진을 추가하고 바꾸는 동작을 찾기 어려움.
- 사진 보관함에서 칸으로 드래그하고 이미 배치한 사진끼리 교환하고 싶음.
- 결혼식 포토테이블 / 벽걸이용 액자에 넣어 출력하는 맥락이 필요함.

## 구현
1. 사진 원본 배열과 배치 ID 배열 분리. 비어 있는 칸 유지. 개수 축소 시 보관함 유지. 되돌리기에서 원본/배치 함께 복원.
2. 미리보기 바로 아래 사진관리: 다중 추가, 전체/미배치 필터, 사진별 편집·보관함 삭제, 빈칸 자동 채우기. 배치된 칸의 제거는 보관함 원본을 지우지 않음.
3. PC 보관함→칸 드래그, 칸↔칸 교환. 모바일/키보드: 사진 선택 후 칸 선택. 기존 사진도 보관함에서 선택 가능. 같은 사진 중복 배치 대신 위치 이동/교환.
4. 하트는 사진을 자르는 전역 마스크 없이 정사각 타일을 유지. 넓은 상단, 크기 차가 있는 양쪽 봉우리와 작아지는 하단으로 폭/높이 비율 개선. 개수별 썸네일과 공통 렌더링 사용.
5. 문장별 줄바꿈과 keep-all 적용, 주요 라벨 가독성 보완.
6. 액자 출력: A5~A2 + 5×7/8×10인치, 사용자 지정 종이 크기. 액자용/포스터용, 기본/넉넉한/최소 여백, 3/5/8mm 가림 여유. 액자 시뮬레이션은 출력에서 제외. 실제 액자의 종이 수납 크기와 매트 창 크기 차이를 안내.
7. 자동 테스트: 배치 손실/중복/빈칸, 사이즈 변경/삭제/복원, 모든 하트·용지·간격·여백 경계. 실제 앱 다중 선택→추가→배치→저장 검수. 확인 못한 환경은 명시.
8. PRD/결정/검수기록 갱신, GitHub master 반영, Vercel 배포 성공 및 배포 파일 확인.
