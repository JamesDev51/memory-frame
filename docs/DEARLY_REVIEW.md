# Dearly 참고 검토

참조: https://dearly.kr/frame (2026-09-07 공개 페이지 조회)

확인한 내용: 서비스는 폴라로이드 액자를 명시하며 보관함에서 칸 채우기, 칸 선택 후 확대/위치 조정, A3/A5, 흑백/컬러를 제공한다. 그림자는 여러 차례 직접 인쇄해 조정했다고 안내한다. 정확한 배치 치수/간격/테두리 폭은 텍스트 자료로 확인 불가하며 브라우저 화면 요청은 timeout이었다.

우리 구현은 일반적인 폴라로이드 디자인 원칙을 독립 적용했다. 카드 비율1:1.22, 상단/좌우6%, 정사각 사진창88%, 하단28%폭 상당 여백. 원본 코드를 복제하거나 경쟁사의 인쇄 검증을 우리 결과의 검증으로 주장하지 않는다.
