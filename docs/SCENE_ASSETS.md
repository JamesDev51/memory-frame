# 공간 미리보기 배경

Built-in image_gen으로 생성. 사용자 사진을 입력하지 않았음. 원본은 생성 결과에 보관하고 프로젝트에는 WebP 최적화본을 사용한다.

- public/scenes/wedding-table.webp
- public/scenes/wedding-wall.webp

## Table prompt
Use case: product-mockup. Photorealistic wedding photo table background. Landscape 1536x1024. Straight-on eye-level camera, warm cream plaster wall, ivory linen tabletop, white roses and greenery far left, ivory candles far right. Center unobstructed blank wall and empty tabletop for dynamic frame compositing. No frame, artwork, people, text or watermark. Soft daylight from left; restrained contemporary Korean wedding styling.

## Wall prompt
Use case: product-mockup. Photorealistic wedding venue wall background. Landscape 1536x1024. Straight-on camera, pale warm ivory plaster wall and afternoon window light. Low oak console at bottom, white blossoms far right, curtain extreme left. Center wall blank for a dynamically inserted frame. No frame, painting, mirror, signage, text, people or watermark.

Generated images were resized to width1200 and encoded WebP quality78 for web delivery. Frame is rendered separately; no regeneration per user.
